Cách cài trên iPhone / iPad
  1. Tải tệp MotionCut.ipa về máy.
  2. Mở AltStore, Sideloadly hoặc TrollStore rồi chọn tệp .ipa để cài.
  3. Không muốn dùng IPA? Mở motioncut.io.vn bằng Safari → Chia sẻ → Thêm vào Màn hình chính.
Cách cài trên Android
  1. Tải tệp .apk về máy rồi mở tệp.
  2. Khi hệ thống hỏi, cho phép cài từ nguồn không xác định.
  3. Hoặc mở motioncut.io.vn bằng Chrome → ⋮ → Cài đặt ứng dụng.
Cách cài trên Windows / Linux / macOS
  1. Windows: tải tệp .exe và chạy để cài. Nếu Windows SmartScreen báo, chọn Thông tin thêm → Vẫn chạy.
  2. Hoặc mở motioncut.io.vn bằng Chrome/Edge và bấm biểu tượng Cài đặt ở thanh địa chỉ.
